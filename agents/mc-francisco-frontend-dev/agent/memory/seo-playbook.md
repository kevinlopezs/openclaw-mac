# SEO Playbook — Francisco

- React + Next.js + Tailwind con foco en:
  - SEO técnico (SSR/SSG/ISR, metadatos, estructura semántica).
  - Core Web Vitals (LCP/INP/CLS).
  - Contenido orientado a intención de búsqueda y conversión.
- No tocar APIs ni modelos: actuar en capas de UI/UX, routing, metadata y contenido.
- Landings y páginas de servicios: preferir SSG/ISR, con hero ligero, CTAs claros y secciones de beneficios, proceso, casos de estudio y FAQs.
- Usar siempre que sea posible `next/image`, headings correctos, buen contraste, accesibilidad y arquitectura de enlaces internos (blog ↔ servicios ↔ contacto).
